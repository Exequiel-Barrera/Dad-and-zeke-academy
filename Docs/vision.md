# Dad & Zeke Academy

## Vision

Dad & Zeke Academy is a personalised learning platform designed to help children develop confidence, curiosity and a love of learning through interactive adventures.

The app follows the New Zealand Curriculum while making learning feel like play.

Our mission is simple:

**Learn. Build. Explore. Together.**

## Core Values

- Learning should be fun.
- Mistakes help us grow.
- Parents learn alongside their children.
- Small progress every day creates big results.

## First Goal

Build an application that Zeke genuinely enjoys using and that helps him improve his reading, writing, maths and confidence.
